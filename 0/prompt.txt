# 実装依頼

## 依頼
新規 Devsy workspace の名前に、Orca ephemeral VM ID の末尾を使うよう変更する。

## 目的
- Orca に表示される VM 名と Devsy workspace ID の対応を、目視で確認できるようにする。

## 成功条件
- 新規 workspace の名前が `<リポジトリ名>-<動物名>-<Orca VM ID の末尾8文字>` となる。
- 例えば Orca の表示名が `glaze VM 0a9e2d2f` の場合、workspace ID が `glaze-ferret-0a9e2d2f` のようになる。
- workspace 名全体が使用済みの場合、末尾を維持して動物名を変え、再試行する。
- 既存 workspace の名前と保存済みの対応関係は変更しない。

## 決定事項
- `ORCA_VM_INSTANCE_ID` の末尾を workspace 名の末尾に使う。
  - 理由: Orca の表示名と Devsy workspace ID を対応付けられる。
  - 主な棄却案: 独立したランダム文字列を使う案は、目視で対応付けられない。
- 衝突判定は workspace 名全体について行い、末尾だけの衝突を防ぐ特別な処理は設けない。
  - 理由: Orca 側でも末尾だけでは一意性を保証しておらず、アダプターだけで防ぐ必要はない。
  - 主な棄却案: 同じ末尾を持つ workspace の作成を停止する案は、目的に対して過剰。
- 名前全体が使用済みの場合は、動物名を変更して再試行する。
  - 理由: 現在の重複回避を維持しつつ、Orca の表示名との一致を保つ。
  - 主な棄却案: 即座に作成を停止する案は、動物名を変えれば作成できる場合にも失敗する。

## 制約
- Devsy workspace ID の既存の文字種と長さの制約を満たす。
- 既存環境を移行・変更しない。

## 対象外
- Orca の表示名の変更。
- 既存 workspace の改名や移行。

## 未検証の前提
- 実装時に、使用する Orca の VM ID が recipe に渡される `ORCA_VM_INSTANCE_ID` と一致することを確認する。
- Orca の表示名に使われる末尾の取り方と、対応する入力の扱いを確認する。

## 実装時の指示
- 既存の workspace 名生成と重複時の再試行を調整し、命名・長さ制約・重複時の動作を検証する。
